## 구조와 성능

하나의 Salvo가 시간차 발사를 관리하고 실제 발사 시점에 살아 있는 표적을 고른다. Enemy ID별 Map에 비행 중 예상 피해를 합산하여 이미 충분히 예약된 약한 표적을 피한다. 강적/방패에는 필요한 만큼 집중 가능하다. 정확한 미래 피해 예측은 하지 않는다. Focus도 예약을 무시하지 않는다.

M9의 실제 Frame당 Enemy Render, readonly snapshot/검증된 ID index, 이벤트 기반 Target 검색, VFX 상한/Graphics 재사용을 유지한다. Grenade·Drone·Gauss·Horde·Enemy HP·XP·Relic·Core·Synergy·Boss의 기본값은 수정하지 않는다. 새 Asset·물리 엔진·Pool Framework는 없다.

미사일 Primitive만 조금 크게 하고 기존 Graphics 안의 trail을 늘린다. 실제 시간차 발사가 여러 발을 구분한다. M9 VFX 상한16/frame·64active·96impact targets는 유지한다.

약점 고정과 위협 릴레이의 기존 역할은 유지한다. 재유도/연쇄/반복은 모두 남은 수명을 소비한다. 긴급 재지정 회복에도 횟수 한계가 있으므로 무한 미사일은 없다. 수명 배율은 Tracking과 Immortal 중 큰 값을 사용하며 곱연산으로 폭증시키지 않는다.

## Salvo / Reservation 경계

- 한 개의 진행 중 Salvo만 유지한다. Cycle은 `max(성장 적용 주기, (발수−1)×간격)` 이상이며 무제한 발사 예약 Queue를 만들지 않는다.
- 발수·간격·스탯·행동 배율은 Salvo 시작 때 고정한다. 과충전 유물은 행동당1회, 치명타는 실제 발사된 탄마다 판정한다. 매 발 실제 생성 시점에 표적을 고른다.
- 예약은 아직 발사하지 않은 탄을 포함하지 않는다. 현재 본체HP+ShieldHP에서 비행 탄의 예상 피해를 뺀다. 피해 예상에는 현재 강적/압박/시너지/보호 배율을 반영하되 미래 모든 공격이나 방패 우회를 완벽히 예측하지 않는다.
- 표적 변경 전에 이전 예약을 해제한다. 명중·수명 종료·재유도 횟수 소진·유효 표적 없음 경로에서도 해제한다. ON/OFF와 무관하게 예약 장부는 유지하며 OFF에서는 표적 필터만 무시한다.
- 모든 적이 이미 충분히 예약돼 있으면 해당 발을 생략한다. 스웜도 새로운 표적이 없으면 아직 예약 피해가 부족한 강적에는 다시 집중할 수 있다. 낭비 방지 때문에 기본3발이 모든 상황에서 무조건 생성되는 것은 아니다.
- 속도 조절은 비행 중 탄에 즉시 적용된다. 발수/간격/기본 피해/주기는 다음 Salvo부터, 재유도 횟수와 수명은 새로 생성되는 탄부터 반영한다.

## 개발 패널

한국어 미사일 영역에 기본 발수·발사 간격·Salvo 주기·발당 피해·속도·기본 재유도·수명·예약 ON/OFF·포화 추가 발수 Lv3/6/10·Hunter 강적 피해·Tracking 추가 재유도·긴급 재지정 추가 재유도를 표시한다. Tooltip과 적용 시점을 제공한다. 간격/주기/수명은 X1 초로 표시하고 JSON은 raw combat ms를 저장한다.

기존 `special.missileBehavior.saturation.count.*`는 절대 발수였고 새 `additionalCount.*`는 기본 발수에 더하는 값이다. 옛 키를 포함한 Preset/JSON은 기존 검증에서 명확히 거부한다. 뜻이 다른 숫자를 몰래 변환하지 않으며 새 항목으로 다시 저장해야 한다.
