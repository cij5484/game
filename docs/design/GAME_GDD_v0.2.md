# GAME GDD v0.2

> **Current Source of Truth — 자동 공격 / 선택형 성장 / 고유 필살기 제스처**
> 기존 `GAME_GDD_v0.1.md`는 과거 설계 기록으로 원문 보존합니다. 현재 게임 규칙은 이 문서와 Technical Spec, `src/game/data/`를 따릅니다. 아래 수치는 모두 prototype tuning이며 플레이테스트 후 변경할 수 있습니다.

## 1. 게임 비전과 성장 철학

모바일 웹 2D Horde Defense + Roguelite. 성벽 위 고정 Marine이 위쪽에서 몰려오는 적을 막고, 처치 → 경험치 → 선택 → 행동 변화로 성장합니다. 핵심은 자동 사격 위에서 위험 적을 직접 지정하는 터치 판단, 빌드 분기 선택, 대규모 군세 정리와 조합 완성입니다. 항목 수를 늘리기보다 정해진 핵심 항목의 Lv3 선택과 Lv5 결실로 Run의 차이를 만듭니다. 장기적으로 5~6명 친구 간 기록과 빌드 비교를 목표로 합니다.

**“플레이어도 미쳐가고 몬스터도 같이 미쳐간다.”** 레벨업·유물 강화·특성 Lv.5의 쾌감을 억제하여 난이도를 만들지 않습니다. Horde 수, spawn intensity, Runner/Shield/Elite 비중과 조합이 주요 난이도 수단입니다. Grunt를 HP sponge로 만들지 않습니다. 전설 없이도 클리어 가능한 밸런스가 목표이며, 전설은 의도적으로 강력한 판을 허용합니다. 실제 승률과 재미는 사용자 플레이테스트로 판정합니다.

## 2. 현재 구현과 미래 설계 구분

현재: **전투 시뮬레이션 300초 Run**, Marine/가우스 소총/스팀팩, 마법 2종, 적 3종과 Grunt 기반 Elite, 특성 5종(A/B 분기), 유물 8종, 희귀 코어 4종, 선택형 시너지 5종, 진화 1종, 필살기 1종. 성벽 HP 12,000이며 300초 생존은 승리, HP 0은 패배입니다. Graybox 표현이며 로컬 Run 저장·불러오기, 영구 보상·서버는 없습니다. 따라서 이번 삭제 콘텐츠 정리는 현재 후보·타입·표시·효과와 인메모리 상태의 범위이며 실제 저장 파일 마이그레이션은 없습니다.

선택창과 수동 일시정지는 전투 시간을 소모하지 않습니다. 필살기는 준비 상태에서 고유 제스처로 즉시 발동하며 리듬·슬로모션은 없습니다. 실제 한 판의 벽시계 시간은 5분보다 길 수 있습니다. 재도전은 경험치·특성/마법/스팀팩 분기·시너지 선택·집중 타겟·코어·유물·진화·타이머를 모두 초기화합니다.

미래 정식 Stage는 약 15분과 중단 후 Resume를 목표로 합니다. 현재 5분 프로토타입과 혼동하지 않습니다. 이후 시스템은 §13에 구분하며 이번 구현에 포함하지 않습니다.

## 3. 한국어 우선 UI

플레이어 기본 언어는 한국어입니다. 이름·설명·마법·유물·시너지·진화 알림·결과·HUD·버튼·안내 문구를 한국어로 표시합니다. 예: 공격속도, 관통, 도탄, 다중탄, 폭발탄, 치명타, 유물, 진화, 필살기, 준비 완료.

**내부 코드 식별자는 영어**를 유지합니다. 예: `id: "penetration"`, `title: "관통"`. 표시 문구는 data 영역과 각 콘텐츠 정의에 두고, CombatScene 곳곳에 흩어놓지 않습니다. 소규모 표시 문자열 관리로 충분하며 다국어 프레임워크는 도입하지 않습니다. 고유명사는 원문 병기가 가능하고 개발용 Debug Overlay는 영어를 허용합니다.

## 4. 전장 / Portrait / Full-Bleed

- 공식 방향은 Mobile Portrait. 9:16, 9:19.5, 9:20, 세로 태블릿에 대응합니다.
- 최상단 먼 전장/Spawn → 중앙 교전 → 하단 성벽/Marine/통합 HUD. 배경은 화면 끝까지 채우며 검은 letterbox를 기본으로 쓰지 않습니다.
- 720×1280은 논리 표현 기준이며 Phaser Scale Manager RESIZE로 대응합니다. 긴 화면의 여유는 먼 환경, 넓은 화면의 여유는 주변 환경으로 흡수합니다.
- 3 Soft Lane `left/center/right`, lane 내부 lateral offset, 논리 `progress01` 0=Spawn/1=성벽. 이동시간·논리 거리·공격 판정은 physical pixel/visual scale과 분리합니다.
- Fake Perspective는 가까워질수록 시각적으로 커집니다. 공격 slot의 deterministic offset은 성벽 앞 겹침을 줄이는 시각 배치이며 피해·도착시각을 바꾸지 않습니다.
- 복잡한 pathfinding, enemy 물리충돌, physics projectile 없이 가벼운 상태 계산과 hitscan을 사용합니다.
- 상단 Build Bar는 획득한 강화·무기 특성·유물의 기호와 레벨, 코어·활성 시너지의 작은 기호를 표시하며 상세 설명은 일시정지에 둡니다. 하단 성벽은 HP·레벨/XP·시간과 스팀팩/서리장/번개/필살기 4칸으로 구성합니다. 스팀팩 단계와 각 능력 진행도·대기·준비 상태를 계속 표시하며 준비 링·색상·한국어 상태로 사용 가능 여부를 명확히 구분합니다. 일시정지는 우측 최상단 작은 아이콘, 미보유 빈 슬롯은 표시하지 않습니다.
- `viewport-fit=cover`, safe-area inset을 반영하되 배경은 Full-Bleed. HUD와 전장 root는 분리합니다.

## 5. 입력 / 자동 사격 / 집중 타겟

| 입력 | 행동 |
| --- | --- |
| 입력 없음 | Fire Rate에 따라 연속 자동 사격, Smart Auto Target |
| 살아있는 적 Tap / 왼쪽 클릭 | 해당 적을 지속 집중 타겟으로 지정 |
| 빈 전장 Tap / 왼쪽 클릭 | 집중 타겟 해제, Smart Auto Target 복귀 |
| 집중 타겟 사망 | 자동으로 Smart Auto Target 복귀 |
| ○ 또는 하단 서리장 아이콘 | 같은 서리장 시전, 같은 대기시간 |
| Z 또는 하단 연쇄 번개 아이콘 | 같은 연쇄 번개 시전, 같은 대기시간 |
| 두 손가락 Tap / PC 좌우 마우스 / 스팀팩 아이콘 | 같은 스팀팩 발동 |
| 준비된 상태에서 V 제스처 | 필살기 즉시 발동 |
| 필살기 아이콘 Tap | V 경로 힌트만 표시, 발동하지 않음 |
| 우측 최상단 일시정지 / 재개 | 게임 시계 정지 / 재개 |

자동 사격의 기본 가우스는발당10·간격200ms의 연속 사격입니다. 이전3발/600ms 주기의 평균 발사율을 유지합니다. 발사 시계가 DPS를 결정하며 연타는 추가탄이나 발사속도를 만들지 않습니다. 수동 타겟은 위협 우선순위만 바꿉니다. 정예·방패를 먼저 제거하거나 성벽 앞 적으로 자동 복귀할 수 있습니다. 표식 특성이나 추가 자원 관리로 수동 타겟을 강요하지 않습니다.

마법·스팀팩 HUD는 실제 터치 버튼이며 충분한 hit area와 한국어 접근성 이름을 갖습니다. Gesture는 숙련 입력, 아이콘은 확실한 fallback이고 성능 차이나 Gesture 전용 보너스는 없습니다. 두 손가락 스팀팩과 PC 동시 입력(120ms 합류/300ms 릴리스)은 유지합니다. 그리기는 최대5초, Tap은300ms이며 작은 jitter는 Tap, 명확한 drawing만 Gesture 후보입니다. 기존 ○/Z 인식 기준과 열린 원 허용은 유지합니다.

## 6. 정해진 항목 안의 선택형 성장

공식 용어는 **강화 카드 / 기본 강화 / 무기 특성 / 특성 개조 / 마법 강화 / 보조 기술 강화 / 유물 / 코어 / 시너지 / 진화 / 비밀 진화 / 필살기**입니다. 강화 카드는 레벨업 선택지 전체이며 **특성 슬롯은 무기 특성만 사용**합니다. 종류와 희귀도는 독립된 축입니다.

| 분류 | 항목 | 성장 / 슬롯 |
| --- | --- | --- |
| 기본 강화 | 공격력·공격속도·치명 확률 | 각5회, 특성 슬롯 미사용 |
| 무기 특성 | 관통·도탄·다중탄·폭발탄·처형탄 | 각Lv1~5, 기본3종/전술 코어4종 |
| 특성 개조 | 무기 특성의 Lv3 A/B 선택 | 해당 특성의 기존 슬롯 유지 |
| 마법 강화 | 서리장·연쇄 번개의 각 성장 트랙 | 각5단계, 특성 슬롯 미사용 |
| 보조 기술 강화 | 스팀팩 성장 트랙 | 5단계, 특성 슬롯 미사용 |
| 시너지 | 해금 조건을 만족한 조합 카드 | 선택 시 활성화, 특성 슬롯 미사용 |

처치 XP는 Grunt/Runner1, Shield3이며 다음 요구 XP는 `8+6(L−1)+2(L−1)²`입니다. 초과 XP·밀린 선택을 보존합니다. 기본 강화는 공격력+15%, 공격속도+6%, 치명 확률+5%p로 각각 최대5회입니다. 기본 치명 확률5%와 피해×1.75를 보존합니다.

성장 트랙은 **Lv1 기능 → Lv2 토대 강화 → Lv3 A/B 선택 → Lv4 선택 분기 강화 → Lv5 Capstone**입니다. Lv3에서 A/B는 같은 선택 화면에 짝으로 등장하고 한쪽을 고르면 반대쪽은 해당 Run에서 잠깁니다. Lv4/5는 선택 분기의 누적 효과 행을 사용합니다. 분기 없는 강제 레벨 상승으로 선택을 건너뛰지 않습니다.

최종 Marine 특성은5종입니다. 소이탄·표식탄·제압탄·과열과 이들에 연결된 상태/Recipe/HUD를 제거합니다. 더 이전의 분열탄·중량탄·치명타 특성도 돌아오지 않습니다. 별도 전설 무기 행동 카드3종은 분기 Capstone과 역할이 겹쳐 정리하고 Lv5 카드가 큰 성장 순간을 담당합니다.

### 무기 특성의 토대와 분기

수치는 `src/game/data/traits.ts`의 누적 행이며 이전 레벨에 덧셈하지 않습니다. 각도는 논리rad, 반경은 논리 거리입니다.

| 특성 | Lv1 → Lv2 | Lv3 A → Lv4 → Lv5 | Lv3 B → Lv4 → Lv5 |
| --- | --- | --- | --- |
| 관통 | 1명/65% → 2명/75% | **직선 관통:** 3명/85% → 5명/95% → **무손실 관통:** 8명/100%, 방패 감소50% 무시 | **파쇄 관통:** 2명/75%, 반경100·90% → 2명/85%,135·130% → **대형 파쇄:** 3명/90%,180·180%, 방패 완전 무시 |
| 도탄 | 1회/65% → 2회/75%·거리+30 | **연쇄 도탄:** 4회/75%·거리+80 → 6회/85%·+120·1명 분기 → **전장 연쇄:** 8회/100%·+160·3명 분기 | **강타 도탄:** 2회90→135% → 2회110→175% → **파괴 도탄:** 3회130→220→310%, 끝 반경100·150% 충격파 |
| 다중탄 | 보조1발55%/0.65rad → 1발80%/0.75rad | **광역 사격:** 보조2발70%/0.95 → 4발80%/1.15 → **전면 탄막:** 6발90%/1.3 | **집중 사격:** 보조1발115%·중앙115%/0.22 → 1발150%·중앙130%/0.20 → **집중 일제사격:** 2발200%·중앙160%/0.18 |
| 폭발탄 | 반경65/40% → 85/60% | **연쇄 폭발:** 반경100/70%·처치2명 추가폭발 → 115/85%·4명 → **연쇄 붕괴:** 130/100%·6명 추가폭발(125/100%), 재연쇄 없음 | **압축 탄두:** 125/100% → 155/140% → **초대형 기폭:** 190/190%, 추가폭발 없음 |
| 처형탄 | 최대HP10% 이하 → 15% 이하 | **사형 집행:** 25% → 32% → **최후 통첩:** 40% 이하, 정예·방패 동일 | **죽음의 파동:** 15%/반경110·120% → 18%/145·170% → **집단 선고:** 20%/190·230%, 약해진 주변4명 추가처형·재파동 없음 |

같은 발의 겹치는 타격은 가장 강한 피해 한 번으로 합칩니다. 기본 공격은 발당128대상·64범위사건, 범위당24대상 한도를 둡니다. 원거리/측면의 타겟 배치에 따라 관통·부채꼴·도탄의 실제 대상 수는 달라집니다.

### 선택 카드와 코어

일반/희귀/유니크/전설의 기본 가중치10/4/1/0.25와 투자tag당+8% bias(최대×1.6), 특성 카드 가중치×2를 보존합니다. 기본 후보3장, 선택 확장 코어는4장입니다. Lv3 A/B는 유니크, Lv5는 전설 표시를 사용하며 카드 희귀도와 성장 레벨은 별개입니다. MAX/꽉 찬 새 특성/반대 분기/이미 선택한 시너지는 제외합니다. Reroll은 없습니다.

코어는 정예 처치 시8% 별도 추첨, Run당 최대2개·중복 없음·레벨 없음입니다.

| 코어 | Run 규칙 |
| --- | --- |
| 전술 확장 코어 | 무기 특성3→4종 |
| 유물 확장 코어 | 유물3→4종, 즉시 유물 선택1회 |
| 선택 확장 코어 | 레벨업 후보3→4장 |
| 공명 코어 | 선택해서 활성화한 시너지 효과×1.5, 안전 상한 유지 |

행운 코어는 선택 확장으로 교체합니다. 과부하 코어는 Lv3 분기 선택을 건너뛰지 않도록 제거하며 두 카드 선택/추가 Capstone은 이번에 추가하지 않습니다. 코어는 시너지 Recipe 재료로 남발하지 않습니다.

## 7. 시너지 선택 / 진화

자연 상호작용은 기존 효과가 동시에 적용되는 것이고, 시너지는 조합을 선택해 새 행동을 여는 것입니다. 진화는 높은 조건에서 시스템을 상위 형태로 바꾸며 비밀 진화는 복잡한 숨은 고급 조합의 미래 설계입니다. 비밀 진화는 현재 없습니다.

**조건 충족 → 카드 해금 → 레벨업에서 선택 → 활성화** 순서를 따릅니다. 조건만으로 전투 효과가 켜지지 않습니다. 미선택 해금 시너지가 있으면 다음 선택에 한 자리를 보장하고, 여러 개면 덜 제시된 조합부터 순환해 RNG만으로 끝까지 누락되는 것을 막습니다. 카드는 시너지 종류와 전용 기호로 구별하며 특성 슬롯을 소모하지 않습니다. 선택할 때 짧은 완성 알림, Build Bar 기호, 일시정지 조건/효과를 표시합니다.

| 시너지 | 카드 해금 조건 | 선택 후 행동 |
| --- | --- | --- |
| 심층 폭발 | 관통≥1 + 폭발탄≥1 | 관통 적중마다 폭발 |
| 살상 도탄 | 도탄≥1 + 치명 확률 기본 강화≥1 | 치명 피해를 도탄에 이어가고 도탄+2회 |
| 탄막 폭풍 | 다중탄≥1 + 공격속도 기본 강화≥3 | 매4번째 발사에 추가2탄 |
| 집속 폭격 | 다중탄≥1 + 폭발탄≥1 | 중앙 강화 폭발·보조 소형 폭발 |
| 즉결 폭파 | 처형탄≥1 + 폭발탄≥1 | 처형 지점에서 강한 폭발, 재귀 처형 없음 |

소이·표식·제압·과열 관련7개 시너지는 삭제합니다. 조합 카드를 별도 콘텐츠 숫자 채우기에 사용하지 않습니다. 조건과 선택 상태는 별도로 보존하고 Run 재시작 때 초기화합니다.

초관통 가우스(Hyper Gauss)는 **관통Lv4 + 테슬라 코일Lv3**이며 관통A/B 어느 분기에서도 조건을 만족할 수 있습니다. 추가 관통3명·폭×1.6·강화 청록 tracer를 유지합니다. 시너지 카드와 다른 진화 계층이며 조건 충족 시 Run당1회 자동 진화합니다.

공성 증폭기·얼음 심장·자극 회로·행운 동전은 후보/현재 효과에서 제거합니다. 테슬라 코일·광전사 인장·시간 톱니의 기존 수치는 보존합니다. 최후의 보루는 저HP 상시 피해 보너스가 아닌 **피해를 받은 뒤 성벽이 살아 있고 HP30% 이하일 때 Run당1회 발생하는 사건**입니다. 광전사의 성벽 비용은 최소1을 남기며 실제 발동 조건을 만족한 경우만 소모합니다.

탄약 복제기는 보라색 강화 궤적으로 원본과 구별하며, 해당 자동 사격180ms 뒤 원래 대상과 다른 살아있는 적을 찾아 복제 사격을 시작합니다. 실제 자동 사격3발을 내부 집계1회로 묶어8/6/5/4/3회마다 발동하므로 화면 설명은24/18/15/12/9발입니다. Lv1~2는2발, Lv3 이상은3발을 복제합니다. Lv5는 보유5종 특성 레벨·선택 분기·선택 완료 시너지를 계승하지만 원본의 진화·스팀팩·마법 피해 버프는 복제하지 않습니다. Lv3~4의 경로 특성은 관통·도탄·다중탄이며 보유 레벨을 각각Lv1/2까지 계승하고 분기는 계승하지 않습니다. 복제 큐4개이며 복제는 복제를 다시 만들거나 유물 명중 충전을 재발동하지 않습니다. 서리 공진기는 서리장의 지속시간을 늘리지 않고 서리 중 대상별 기본 명중으로 취성을 쌓습니다. 발당 파동 수와 총24대상 한도로 재귀/연쇄 폭증을 막습니다. Lv4 이상 파쇄가 전달한 취성은 다음 명중을 준비하며 같은 사건에서 즉시 재파쇄하지 않습니다.

아드레날린 펌프의 연장 상한은 **스팀팩 1회 기준**입니다. 실제 연장분의50%를 회복 단계에 더하며 **선택한 스팀팩 분기의 탈진은 보존**합니다. 긴급 회수는 progress≥0.85의 처치만 인정하고 최근1초 이벤트 수로 회복을 제한합니다. 회복은 성벽 최대치, 에너지는 필살기 최대치, 마법 대기는0으로 제한합니다. 긴급 치명 방지는 HP1을 남기고1.2초 보호와 progress0.16 밀침을 줍니다. 긴급 치명 방지와 최후의 보루는 각각 Run당1회이며 재시작 전 회복·재획득으로 다시 충전하지 않습니다.

**관통 Lv4 + 테슬라 코일 Lv3 → 초관통 가우스**. 모든 유물 MAX 도달은 보장하지 않습니다. 이벤트 유물의 실제 효율·위기 연출 인지와 스팀팩의 분기 대가는 플레이테스트로 조정합니다.

## 9. 마법 / 스팀팩 분기 / 고유 필살기

마법은 처음부터 사용 가능하고 성장 rank0에서 시작합니다. 각 마법 강화 트랙은5장 투자로 끝나며 Lv3에서 A/B를 선택합니다. 서리 강도·지속·번개 대상·거리 등을 각각 반복하는 기존 개별 카드는 이 트랙으로 통합합니다. 새 성장 카드가 이미 진행 중인 마법 대기를 초기화하지 않으며 빈 전장 시전도 대기를 소모합니다.

서리 기본은 전역 이동×0.5·7초·대기30초이며 신규 Spawn에도 적용합니다. 전장 제어Lv5는 총14초·이동×0.12입니다. 파쇄의 처치 파열은 반경100/120/150, 전체 대상24/32/40, 한 처치 처리당 최대8중심·중심당12명과 Lv5 깊이2로 제한합니다. 전역 감속은 성벽 공격·Spawn·Primary·다른 대기의 시계를 늦추지 않습니다.

번개 기본은 반경360·최대30명·피해75·대기24초입니다. 연쇄 분기는 총64대상 한계이며 낙뢰Lv5 추가낙뢰는 반경150·회당8명·대기큐3회 한계입니다. 정예/성벽 위협을 우선하지만 수동 기본공격 집중 타겟과 동일한 기능으로 혼동하지 않습니다.

스팀팩 기본은 강화5초·공속×1.5 → 탈진1초 → 회복2초입니다. 고농도는 화력과 긴 회복의 교환이며 탈진1초를 유지합니다. 안정은 화력을 낮추는 대신 **명시적으로 탈진·회복을 줄이는 분기**입니다. 아드레날린 펌프는 선택 분기의 탈진을 다시 바꾸지 않고 실제 Boost 연장분의50%를 회복 부담에 추가합니다. 재투약C는 이번에 구현하지 않습니다.

### Marine 필살기 — V 제스처

Gauge100에서만 Ultimate recognizer를 켭니다. 한 손가락으로 **왼쪽 위 → 아래 꼭짓점 → 오른쪽 위의 V**를 그리며 역방향도 허용합니다. 필살기 아이콘 Tap은 경로 힌트만 보여주고 Gauge를 소비하거나 공격하지 않습니다. 인식 성공 시 Gauge를 즉시0으로 만들고 억제 사격을 한 번 발동합니다.

후보 비교에서 삼각형·loop는 ○와 폐곡선이 겹치고, 옆 chevron은 방향 혼동과 Z의 불완전획 위험이 있습니다. 열린V는 상단의 두 끝점·한 개의 아래 꼭짓점으로 ○/Z와 분리됩니다. 인식은 최소폭/높이55 CSS px, 크기 정규화, 경로거리33샘플, 양변 직진성으로 판단합니다. 작은 기울기·손떨림·샘플밀도 차이를 허용하며 준비 전 V, ○, Z, 닫힌 삼각형, 옆 chevron, 역V, U곡선, 낙서는 거절합니다. 실제 모바일 재현성은 별도 플레이테스트 대상입니다.

**억제 사격은 항상 최대60명·대상당140피해**, 성벽 가까운 살아있는 적부터 선택하고 방패 저항·무기 특성에 독립적입니다. 650ms 연출은 시각 표시와 선택창 표시 지연만 담당하고 자동 사격·마법·스팀팩·타겟 입력을 막지 않습니다. 리듬 state, 3초 대기, 타이밍5회, PERFECT/GOOD/MISS, 점수·등급 배율, 슬로모션과 리듬 입력 UI를 제거합니다.

기본 수급은 Gauge100, 명중0.02/처치0.08/정예추가6, 공용 기여 허용량최대3·gameplay초당0.45 회복을 보존합니다. 시간만으로 Gauge는 차지 않고 초과 기여는 저장하지 않습니다. 필살기 자체 처치는 다시 충전하지 않습니다. 5분 높은 처리량+정예7회 기준 한 번 사용 가능한 보수적 예산이며 실제 목표1~2회와 낮은 처리량에서0회 위험은 플레이테스트로 검토합니다.

완화 구간은 30/90/165/210초부터 각각 8초입니다. Lane 가중치는 1/1/1이며 단계 경계에서 새 설정을 적용합니다. 생성 시점의 Run 진행도에 따라 최대 HP ×1→1.10, 이동속도 ×0.65→1.02를 선형 적용하고 이미 생성된 적의 기준값은 유지합니다. 수와 보충 속도가 주된 압박이며 HP 증가는 보조입니다. Grunt/Runner/Shield 기본 속도는 progress/s 0.032/0.08/0.025. 생성 시 최대 HP는 처형 판단에도 사용합니다.

표시 슬롯과 화면비는 논리 거리·이동 시간·피해를 바꾸지 않습니다. D Debug Overlay는 기본 OFF이며 실기기 180마리 성능은 아직 측정하지 않았습니다.

적 수와 처리량이 압박을 만들고 화면비는 난이도를 바꾸지 않습니다. 향후 Bomber/Ranged/Tank/Summoner/Flying 등은 독립된 판단을 요구하도록 설계합니다. Elite/Unique의 고유 행동과 Boss는 후속 검토 대상입니다.

## 11. 결과 / 성능 / 성공 기준

이전 성장·HUD 패스의 검증 기록: `npm.cmd run check` 29개 파일 / 143 tests, TypeScript·Vite build 통과. 제스처 집중 테스트는 38/38 통과했습니다. 번들 크기 1,291.06 kB / gzip 348.35 kB의 기존 500 kB 경고는 남아 있으며, 테스트 통과가 실제 모바일 인식률·재미·180마리 성능 승인을 의미하지 않습니다.

현재 결과는 생존시간, 처치, 레벨, 성벽, 특성/강화/유물/진화를 한글로 보여주고 재도전합니다. 영구 재화나 기록 저장은 없습니다.

모바일 Horde Fantasy는 핵심 요구입니다. 실제 기기에서 FPS, frame spike, memory, 입력 반응을 측정한 뒤 pooling/atlas/공간탐색/VFX budget/먼 적 저빈도 갱신을 선택합니다. cap300은 검증된 성능 예산이 아닙니다. 전용 stress test는 별도이며 과도한 조기 최적화를 하지 않습니다.

성공은 테스트 통과만으로 선언하지 않습니다. Tap/자동·수동 타겟/마법/스팀팩의 사용감, Soft Lane 판단, 선택 후 변화, 후반 쓸어버리는 성장, 5분 재도전 욕구와 실기기 성능을 사용자 플레이테스트로 평가합니다. 실패하면 Final Art/Audio 투자 전 전투 설계를 수정합니다.

### 이번 선택형 성장 패스의 확인 범위

입력 없는 자동 사격·집중 대상 지정/해제/사망 복귀, 5종 특성·마법/스팀팩의 Lv3 양자택일과 반대 분기 차단·Lv5 Capstone, 동일한 Gesture/아이콘 시전·공유 대기, 준비 전 필살기 거절·V 전용 발동·힌트 Tap 비발동, 시너지 조건해금/카드선택/슬롯미사용, 코어 변경, 삭제 데이터 정리를 검증합니다. TypeScript·전체 tests·production build 결과는 해당 완료 보고로 남기며 과거 테스트 숫자와 혼동하지 않습니다. 논리 cap 검증은 실제 모바일 FPS·제스처 인식률을 대신하지 않습니다.

## 12. 개발 원칙

Phaser + TypeScript + Vite, 모바일 웹 우선. balance/recipe/content와 pure logic을 렌더링·입력에서 분리하되 미래 Godot를 위해 과도하게 추상화하지 않습니다. Godot 이전 시 GDD/수치/콘텐츠/공식/아트는 재사용하고 scene/input/render는 다시 구현할 수 있습니다.

Codex는 저장소·구현·테스트·디버깅·빌드·profiling, 설계 협업은 GDD/계획/밸런스/아트 명세를 중심으로 합니다. 작고 승인된 작업 단위로 진행하며 이번 변경은 기존 Milestone12 브랜치에서 commit/push, 사용자 플레이테스트 후 merge 판단. 다음 Milestone 자동 진행 금지.

이번 재설계는 6종 공식 자료의 자동 발사/수동 조준 분리·성장 단계 선택·강한 조합 완성 보상·한정된 능력의 행동 변화 원칙을 적용합니다. 출처와 실제 사실/적용 판단은 [REFERENCE_UI_NOTES.md](REFERENCE_UI_NOTES.md) §5에 있습니다. 성벽·호드·기본 치명타·제스처의 사용자 최신 밸런스는 이 문서의 과거 값으로 덮어쓰지 않습니다.

관리자 Balance Editor, Spawn Console, Run/Time Scale, DPS/Recipe/Wave 도구는 반복 조정이 필요해질 때 도입합니다. 지금은 data 파일과 D Debug Overlay(기본OFF)로 확인합니다. 없는 기능용 GUI/백엔드/최종아트는 추가하지 않습니다.

## 13. 보존한 미래 설계 — 현재 미구현

- **정식 Stage:** 약 15분과 중단 Resume, 여러 encounter/Elite/Unique/Boss. Stage 시작 전 적 종류와 대략적 비중을 공개하되 정확한 순서와 숫자는 숨깁니다. 이전 Stage도 다른 캐릭터/무기/마법/진화/도전으로 재플레이할 가치가 있어야 합니다.
- **마법 슬롯:** 정식 시작 1 → 영구 해금 2 → 최대 3. Gesture는 spell이 아닌 slot에 연결하며 ○/Z/│가 예시입니다. 현재 Prototype은 2종 고정. 미래 Targeted Cast는 Gesture 뒤 위치 Tap이며 Meteor는 미구현입니다. 현재 서리장·번개에는 이미 A/B 성장 분기가 있습니다.
- **Reroll:** 정식 Meta 해금 0 → 1 → 2 → 최대 3/Run. 현재는 없습니다.
- **Recipe 발견:** 진화/시너지/Secret Evolution의 조건은 Hint 전부터 존재합니다. Hint는 권한 해금이 아닌 발견 도움입니다. 캐릭터/무기/마법/유물 발견, Stage/Challenge/Near Miss가 미래 힌트 원천입니다. 발견 후 Codex에 조건을 영구 기록하지만 매 Run 다시 충족해야 합니다. Secret Hint/Near Miss/Codex는 미구현입니다.
- **Run reset:** 레벨/XP/특성/임시 확장/강화/유물/진화. **영구 Meta 후보:** 캐릭터, Weapon Variant, 마법/슬롯, Reroll, Recipe 발견, Mastery, 재화, Stage, Challenge.
- **Firebat 후보:** 소이 특성을 Marine에 되돌리는 대신 별도 화염방사 캐릭터의 정체성 후보로 보존합니다. 현재 미구현입니다.
- **Weapon Family:** Marine의 C-14/Heavy Gauss/Pulse/Rail 등 테마 묶음. Variant는 strict upgrade보다 sidegrade이며 매 Run 기본 상태로 시작합니다. 신규 캐릭터/Variant는 미구현입니다.
- **재화:** Gold는 작은 영구 캐릭터 성장, Credits는 무기/마법/Reroll 등 일반 해금, Core는 캐릭터/슬롯 등 큰 해금에 사용합니다. 역할은 분리하며 현재 경제 시스템은 없습니다. 이번 Run에서 얻는 희귀 코어 4종은 이 미래 영구 재화와 별개입니다.
- **Mastery/Awakening:** 각 스탯 최대 5단계, 초기 약 5%라는 값도 조정 대상, 후반은 고비용입니다. 모든 분야 MAX 이후 비싼 Awakening을 열며 고유 기능/Secondary/Burst/연출 변화를 우선합니다. 단순 깡스탯 증가는 피하고, 두 시스템 모두 현재 미구현입니다.
- **Challenge Modifier:** Stage 클리어 후 이동/HP/Elite/성벽/마법 대기/정보/밀도 등을 직접 조합합니다. Challenge Points가 난이도/보상/점수 배율에 반영됩니다. 별도 Hard/Nightmare 없이 확장하는 장기 방향입니다.
- **친구 기록:** Stage/PB/캐릭터/Challenge/시간/성벽/Elite·Boss/Burst 기록과 Build Summary, Ghost Challenge 후보를 보존합니다. 서버/랭킹/로그인/친구 시스템은 미구현입니다.
- **미래 결과:** 점수/재화/신기록/Codex/Hint/Burst·Elite 성과, 실패해도 진행도 기반 부분 보상을 목표로 합니다. 현재 결과에 영구 보상은 없습니다.
- **Final Art/Audio:** 전투 검증 후 sprite 크기/animation/atlas/VFX 방향과 사격·피격·사망·마법·진화·필살기·성벽·승패 SFX를 검토합니다. 지금은 placeholder입니다. PWA/production save/cloud sync도 범위 밖입니다.
