# GAME GDD v0.2

> **Current Source of Truth — Build System 개편**
> 기존 `GAME_GDD_v0.1.md`는 과거 설계 기록으로 원문 보존합니다. 현재 게임 규칙은 이 문서와 Technical Spec, `src/game/data/`를 따릅니다. 아래 수치는 모두 prototype tuning이며 플레이테스트 후 변경할 수 있습니다.

## 1. 게임 비전과 성장 철학

모바일 웹 2D Horde Defense + Roguelite. 성벽 위 고정 Marine이 위쪽에서 몰려오는 적을 막고, 처치 → 경험치 → 선택 → 행동 변화로 성장합니다. 핵심은 터치 전투, 빌드 선택, 대규모 군세 정리, 큰 폭의 성장, 조합 발견입니다. 장기적으로 5~6명 친구 간 기록과 빌드 비교를 목표로 합니다.

**“플레이어도 미쳐가고 몬스터도 같이 미쳐간다.”** 레벨업·유물 강화·특성 Lv.5의 쾌감을 억제하여 난이도를 만들지 않습니다. Horde 수, spawn intensity, Runner/Shield/Elite 비중과 조합이 주요 난이도 수단입니다. Grunt를 HP sponge로 만들지 않습니다. 전설 없이도 클리어 가능한 밸런스가 목표이며, 전설은 의도적으로 강력한 판을 허용합니다. 실제 승률과 재미는 사용자 플레이테스트로 판정합니다.

## 2. 현재 구현과 미래 설계 구분

현재: **전투 시뮬레이션 300초 Run**, Marine/가우스 소총/자극제, 마법 2종, 적 3종과 Grunt 기반 Elite, 특성 6종, 유물 2종, 시너지 3종, 진화 1종, 필살기 1종. 성벽 HP 12,000이며 300초 생존은 승리, HP 0은 패배입니다. Graybox 표현이며 저장·영구 보상·서버는 없습니다.

선택창과 수동 일시정지는 전투 시간을 소모하지 않습니다. 필살기 리듬 구간은 전장/Run 시간이 0.08배로 흐릅니다. 실제 한 판의 벽시계 시간은 5분보다 길 수 있습니다. 재도전은 경험치·특성·확장·유물·진화·타이머를 모두 초기화합니다.

미래 정식 Stage는 약 15분과 중단 후 Resume를 목표로 합니다. 현재 5분 프로토타입과 혼동하지 않습니다. 이후 시스템은 §13에 구분하며 이번 구현에 포함하지 않습니다.

## 3. 한국어 우선 UI

플레이어 기본 언어는 한국어입니다. 이름·설명·마법·유물·시너지·진화 알림·결과·HUD·버튼·안내 문구를 한국어로 표시합니다. 예: 속사, 관통, 도탄, 다중탄, 폭발탄, 치명타, 유물, 진화, 필살기, 준비 완료.

**내부 코드 식별자는 영어**를 유지합니다. 예: `id: "penetration"`, `title: "관통"`. 표시 문구는 data 영역과 각 콘텐츠 정의에 두고, CombatScene 곳곳에 흩어놓지 않습니다. 소규모 표시 문자열 관리로 충분하며 다국어 프레임워크는 도입하지 않습니다. 고유명사는 원문 병기가 가능하고 개발용 Debug Overlay는 영어를 허용합니다.

## 4. 전장 / Portrait / Full-Bleed

- 공식 방향은 Mobile Portrait. 9:16, 9:19.5, 9:20, 세로 태블릿에 대응합니다.
- 최상단 먼 전장/Spawn → 중앙 교전 → 하단 성벽/Marine/통합 HUD. 배경은 화면 끝까지 채우며 검은 letterbox를 기본으로 쓰지 않습니다.
- 720×1280은 논리 표현 기준이며 Phaser Scale Manager RESIZE로 대응합니다. 긴 화면의 여유는 먼 환경, 넓은 화면의 여유는 주변 환경으로 흡수합니다.
- 3 Soft Lane `left/center/right`, lane 내부 lateral offset, 논리 `progress01` 0=Spawn/1=성벽. 이동시간·논리 거리·공격 판정은 physical pixel/visual scale과 분리합니다.
- Fake Perspective는 가까워질수록 시각적으로 커집니다. 공격 slot의 deterministic offset은 성벽 앞 겹침을 줄이는 시각 배치이며 피해·도착시각을 바꾸지 않습니다.
- 복잡한 pathfinding, enemy 물리충돌, physics projectile 없이 가벼운 상태 계산과 hitscan을 사용합니다.
- 상단은 가능한 한 Battlefield 전용. 하단 성벽에 HP·레벨/XP·유물·마법 대기·필살기·시간을 작게 배치합니다. 특성은 선택창 요약과 결과창에 표시하여 하단 공간을 확보합니다. 일시정지는 우측 최상단의 작은 아이콘이며 한국어 접근성 이름을 제공합니다. 없는 시스템의 빈 슬롯은 만들지 않습니다.
- `viewport-fit=cover`, safe-area inset을 반영하되 배경은 Full-Bleed. HUD와 전장 root는 분리합니다.

## 5. 입력 / 기본 전투 / 자극제

| 입력                               | 행동                                           |
| ---------------------------------- | ---------------------------------------------- |
| 적 hitbox 밖 전장 Tap / 왼쪽 클릭  | 성벽에 가장 가까운 살아있는 적을 자동 공격     |
| 적 Tap / 왼쪽 클릭                 | 그 명령만 해당 적 우선, persistent lock 없음   |
| ○                                  | 서리장 즉시 시전                               |
| Z                                  | 연쇄 번개 즉시 시전                            |
| 두 손가락 Tap                      | 자극제                                         |
| PC 좌우 마우스 동시 클릭           | 자극제: 120ms 내 두 버튼 합류, 300ms 내 릴리스 |
| 하단 필살기 버튼                   | Gauge가 가득 차면 수동 활성화                  |
| 우측 최상단 일시정지 아이콘 / 재개 | 전투·리듬·효과를 포함한 게임 시계 정지/재개    |

짧은 jitter는 Tap이고 명확한 drawing만 Gesture 후보입니다. 실패한 Gesture는 오발동하지 않습니다. **기존 Circle recognizer 구조/threshold는 이번 개편에서 변경하지 않습니다.** 터치 자극제 입력도 유지하며 PC 보조 입력만 추가합니다. 적의 touch 영역은 시각 크기보다 조금 넓습니다. 마법 HUD는 입력 버튼이 아닙니다.

기본 가우스는 Tap 1회=3점사, 발당 피해 10, 간격 110ms, 회복 380ms. 무기 상태가 발사 속도를 결정하며 입력 예약은 최대 1개입니다. 연타로 DPS가 증가하지 않습니다. 짧은 tracer/muzzle flash를 사용합니다.

자극제: 정상 → 강화 5초×1.5 → 탈진 1초(Primary 불가) → 회복 2초 → 정상. 강화 지속/배율은 data-driven, 회복은 정상 공격속도로 점진 회복합니다. 탈진 1초는 고정입니다. 강화 선택으로 지속 +0.5초×4, 배율 +0.1×3, 회복 −0.2초×3을 적용할 수 있습니다.

## 6. Weapon Trait와 선택

기존 3개 고정 Build Identity를 **다수 무기 특성**으로 대체합니다. 기본 슬롯 2개, 각 특성 Lv.1~5. 빈 슬롯에서는 새로운 특성을 선택할 수 있고 슬롯이 차면 미보유 특성은 일반 후보에서 제외됩니다. 보유 특성·자극제·현재 마법 성장 후보는 유지됩니다. MAX 제외, 중복 없는 최대 3개 카드 중 하나 선택, Reroll 없음. 후보가 부족하면 유효한 카드만 보여줍니다.

Elite 처치 시 **전술 확장 코어**를 3% 확률로 별도 추첨합니다. 획득하면 이번 Run 특성 한도가 2→3, 유물 슬롯을 사용하지 않으며 중복 확장/4번째 특성은 없습니다. 짧은 한국어 알림을 표시합니다. 재도전하면 한도 2로 초기화됩니다.

레벨업 최대3개·유물1~2개 선택지는 화면 중앙에 가로 정렬한 정사각형 카드입니다. 기호·한글 이름·짧은 효과·일반/희귀/영웅/전설·현재→다음 레벨을 보여줍니다. 전체 효과 설명은 aria/title에 보존하며, 기호는 추후 이미지로 대체할 수 있습니다. 내부 COMMON/RARE/EPIC/LEGENDARY 가중치는 10/4/1/0.25이며 확률 그 자체가 아닙니다. 투자 tag당 +8%, 최대×1.6 build bias와 투자 계열 후보 슬롯을 유지합니다. 장착/사용 가능한 능력과 선행 조건을 필터링합니다.

처치 XP: Grunt/Runner 1, Shield 3. 현재 레벨 L의 다음 요구 XP는 `8 + 6(L−1) + 2(L−1)²`. 초과 XP와 밀린 선택은 보존하며 선택 동안 전투가 완전히 멈춥니다.

향후 후보는 **벽 반사, 유도, 분열, 중탄**. 이번에는 구현하지 않습니다. 벽 반사는 이해 가능한 반사면 설계 전까지 보류합니다.

## 7. 시너지 / 진화

Recipe는 `traits/relics/magic`의 조건을 데이터로 조합하고 공통 판정으로 평가합니다. 특정 Marine 코드에 조건을 하드코딩하지 않습니다.

| 시너지    | 조건              | 실제 행동                                      |
| --------- | ----------------- | ---------------------------------------------- |
| 심층 폭발 | 관통≥1 + 폭발탄≥1 | 관통 과정의 적중 지점마다 폭발                 |
| 살상 도탄 | 도탄≥1 + 치명타≥1 | 치명타 피해를 도탄에 이어가고 치명타 도탄 +2회 |
| 탄막 폭풍 | 속사≥1 + 다중탄≥1 | 매4번째 발사에 온전한 피해 추가 동시탄2발      |

첫 진화: **관통 Lv.4 + 공성 코어 Lv.3 → 초관통 가우스 (Hyper Gauss)**. 추가 관통 +3명, 폭×1.6, 굵기8 청록 tracer. 조건 전에 발생하지 않고 Run당 중복 발동하지 않습니다. 짧은 중앙 진화 알림만 표시합니다. Trait+Trait, Trait+Relic, Magic+Relic, Trait+Magic+Relic 조건을 같은 데이터 형식으로 확장할 수 있습니다.

## 8. 유물 — 구 Module 대체

Elite/Unique 보상이며 레벨업 카드와 별개입니다. 처치 시 전투를 멈추고 유효 후보 중 하나를 선택합니다. 현재 2종, 최대 보유 **3종**, 같은 종류 재획득 시 Lv.1→5. MAX 제외, 슬롯이 차면 새 종류를 후보에서 제한합니다. 교체 UI는 만들지 않습니다. 모든 유물이 MAX면 의미 없는 선택창을 열지 않습니다. Run 종료 시 초기화됩니다.

유물은 관통+1/도탄+1 복제판이 아니라 Primary↔Magic 등 시스템을 연결합니다. 아래 레벨은 이전 효과를 포함합니다.

| 유물        | Lv.1                                         | Lv.2                  | Lv.3                                         | Lv.4                                            | Lv.5                                               |
| ----------- | -------------------------------------------- | --------------------- | -------------------------------------------- | ----------------------------------------------- | -------------------------------------------------- |
| 공성 코어   | 방패 명중마다 번개 대기−60ms, 발당최대240ms  | −120ms, 발당최대480ms | 성공한 마법 사용 후 다음3발 방패 방어 무시   | 5발 방어 무시+방패 피해×1.5                     | 7발 방어 무시+방패 피해×2, 마법마다 성벽120 회복   |
| 테슬라 코일 | 기본공격12발 명중마다 전격1명/피해12/거리240 | 10발마다2명/피해16    | 치명타 명중 추가 충전+2(총3), 전격3명/피해20 | 번개 시전 시 다음명중 전격 준비, 전격4명/피해24 | 6발마다5명/피해30, 전격 적중 시 두 마법 대기−400ms |

전격은 주공격 직접 대상과 중복/재귀 타격하지 않으며, 원래 탄환의 명중 횟수를 또 증가시키지 않습니다. 공성 강화탄은 실제 발사마다 소모합니다. 막힌 마법 입력은 유물을 발동하지 않습니다. 실제 한 Run의 Elite 보상 수가 제한되어 양쪽 유물 MAX를 보장하지 않습니다.

## 9. 마법 / 필살기

현재 ○=서리장, Z=연쇄 번개, 둘 다 추가 위치 지정 없이 즉시 시전합니다. 서리장은 전역 이동속도×0.5/7초/대기30초로 신규 Spawn에도 적용합니다. 성벽 공격속도·Spawn·Primary·다른 cooldown은 느려지지 않습니다. 강화는 감속+4%p×5, 지속+0.6초×5, 서리 tag6 이후 영웅 파쇄 즉시30피해입니다.

연쇄 번개는 논리 거리360 이내 최대30명에게 피해75, 대기24초. 강화는 대상+2×5/피해+12×5/거리+40×4, 번개 tag6 이후 주변 미적중3명60% 분기입니다. 빈 전장 시전도 대기를 소모하고 강화 선택은 남은 대기를 초기화하지 않습니다.

필살기 수급은 이번 변경에서 유지: Gauge100, 명중0.02/처치0.08/Elite추가6. 일반 기여 허용량 최대3, gameplay초당0.45 회복, Elite 보너스는 제한 밖. 시간만으로 Gauge를 채우지 않으며 초과 기여는 버립니다. 자체 Ultimate로 재충전하지 않습니다. 현재 보수적 수치는 5분 최대기여+Elite7회에서도 총180 이하이며, 낮은 처리량에서는 0회 위험이 있습니다.

수동 활성화 후 실제시간3초, 0.5초 간격5회 판정. 완벽±70ms/좋음±150ms/실패, 전장0.08배속. 결과에 따라24~60명/피해60~140의 일제 사격, 모두 실패해도 최소 효과. 빌드별 필살기 변화는 미래입니다.

## 10. 적 / Horde / 성벽

공용 성벽 HP 하나, 별도 플레이어 HP 없음. 도착 후 공격 간격마다 성벽 피해, HP0이면 시뮬레이션 정지. 현재 적은 Grunt HP30/속도0.032/XP1, Runner HP20/속도0.08/XP1, Shield HP60/속도0.025/XP3. Shield Primary 피해배율0.5, Magic은 이 저항을 무시합니다. 속도 단위는 progress/초입니다.

초기65 Grunt, progress0.08~0.45. cap90→중반110~135→후반150~160, 초반900ms마다최대14마리에서 마지막45초500ms마다최대30마리로 지속 리젠을 대폭 높였습니다. 30/90/165/210초부터15초 완화, 총12 encounter와 lane가중치1/1/1. cap에 막힌 spawn은 쌓지 않습니다. 상세 표/가중치는 `horde.ts`와 README를 봅니다. Elite는 Grunt HP×4=120, 금색·확대 표시, 첫60초 이후40초마다 capacity가 허용하면 등장합니다.

적 수와 처리량이 압박을 만들고 화면비는 난이도를 바꾸지 않습니다. 향후 Bomber/Ranged/Tank/Summoner/Flying 등은 독립된 판단을 요구하도록 설계합니다. Elite/Unique의 고유 행동과 Boss는 후속 검토 대상입니다.

## 11. 결과 / 성능 / 성공 기준

현재 결과는 생존시간, 처치, 레벨, 성벽, 특성/강화/유물/진화를 한글로 보여주고 재도전합니다. 영구 재화나 기록 저장은 없습니다.

모바일 Horde Fantasy는 핵심 요구입니다. 실제 기기에서 FPS, frame spike, memory, 입력 반응을 측정한 뒤 pooling/atlas/공간탐색/VFX budget/먼 적 저빈도 갱신을 선택합니다. cap160은 검증된 성능 예산이 아닙니다. 전용 stress test는 별도이며 과도한 조기 최적화를 하지 않습니다.

성공은 테스트 통과만으로 선언하지 않습니다. Tap/자동·수동 타겟/마법/자극제의 사용감, Soft Lane 판단, 선택 후 변화, 후반 쓸어버리는 성장, 5분 재도전 욕구와 실기기 성능을 사용자 플레이테스트로 평가합니다. 실패하면 Final Art/Audio 투자 전 전투 설계를 수정합니다.

## 12. 개발 원칙

Phaser + TypeScript + Vite, 모바일 웹 우선. balance/recipe/content와 pure logic을 렌더링·입력에서 분리하되 미래 Godot를 위해 과도하게 추상화하지 않습니다. Godot 이전 시 GDD/수치/콘텐츠/공식/아트는 재사용하고 scene/input/render는 다시 구현할 수 있습니다.

Codex는 저장소·구현·테스트·디버깅·빌드·profiling, 설계 협업은 GDD/계획/밸런스/아트 명세를 중심으로 합니다. 작고 승인된 작업 단위로 진행하며 이번 변경은 기존 Milestone12 브랜치에서 commit/push, 사용자 플레이테스트 후 merge 판단. 다음 Milestone 자동 진행 금지.

관리자 Balance Editor, Spawn Console, Run/Time Scale, DPS/Recipe/Wave 도구는 반복 조정이 필요해질 때 도입합니다. 지금은 data 파일과 D Debug Overlay(기본OFF)로 확인합니다. 없는 기능용 GUI/백엔드/최종아트는 추가하지 않습니다.

## 13. 보존한 미래 설계 — 현재 미구현

- **정식 Stage:** 약 15분과 중단 Resume, 여러 encounter/Elite/Unique/Boss. Stage 시작 전 적 종류와 대략적 비중을 공개하되 정확한 순서와 숫자는 숨깁니다. 이전 Stage도 다른 캐릭터/무기/마법/진화/도전으로 재플레이할 가치가 있어야 합니다.
- **마법 슬롯:** 정식 시작 1 → 영구 해금 2 → 최대 3. Gesture는 spell이 아닌 slot에 연결하며 ○/Z/│가 예시입니다. 현재 Prototype은 2종 고정. 미래 Targeted Cast는 Gesture 뒤 위치 Tap이며, Meteor와 마법별 2갈래 전문화는 미구현입니다.
- **Reroll:** 정식 Meta 해금 0 → 1 → 2 → 최대 3/Run. 현재는 없습니다.
- **Recipe 발견:** 진화/시너지/Secret Evolution의 조건은 Hint 전부터 존재합니다. Hint는 권한 해금이 아닌 발견 도움입니다. 캐릭터/무기/마법/유물 발견, Stage/Challenge/Near Miss가 미래 힌트 원천입니다. 발견 후 Codex에 조건을 영구 기록하지만 매 Run 다시 충족해야 합니다. Secret Hint/Near Miss/Codex는 미구현입니다.
- **Run reset:** 레벨/XP/특성/임시 확장/강화/유물/진화. **영구 Meta 후보:** 캐릭터, Weapon Variant, 마법/슬롯, Reroll, Recipe 발견, Mastery, 재화, Stage, Challenge.
- **Weapon Family:** Marine의 C-14/Heavy Gauss/Pulse/Rail 등 테마 묶음. Variant는 strict upgrade보다 sidegrade이며 매 Run 기본 상태로 시작합니다. 신규 캐릭터/Variant는 미구현입니다.
- **재화:** Gold는 작은 영구 캐릭터 성장, Credits는 무기/마법/Reroll 등 일반 해금, Core는 캐릭터/슬롯 등 큰 해금에 사용합니다. 역할은 분리하며 현재 경제 시스템은 없습니다.
- **Mastery/Awakening:** 각 스탯 최대 5단계, 초기 약 5%라는 값도 조정 대상, 후반은 고비용입니다. 모든 분야 MAX 이후 비싼 Awakening을 열며 고유 기능/Secondary/Burst/연출 변화를 우선합니다. 단순 깡스탯 증가는 피하고, 두 시스템 모두 현재 미구현입니다.
- **Challenge Modifier:** Stage 클리어 후 이동/HP/Elite/성벽/마법 대기/정보/밀도 등을 직접 조합합니다. Challenge Points가 난이도/보상/점수 배율에 반영됩니다. 별도 Hard/Nightmare 없이 확장하는 장기 방향입니다.
- **친구 기록:** Stage/PB/캐릭터/Challenge/시간/성벽/Elite·Boss/Burst 기록과 Build Summary, Ghost Challenge 후보를 보존합니다. 서버/랭킹/로그인/친구 시스템은 미구현입니다.
- **미래 결과:** 점수/재화/신기록/Codex/Hint/Burst·Elite 성과, 실패해도 진행도 기반 부분 보상을 목표로 합니다. 현재 결과에 영구 보상은 없습니다.
- **Final Art/Audio:** 전투 검증 후 sprite 크기/animation/atlas/VFX 방향과 사격·피격·사망·마법·진화·필살기·성벽·승패 SFX를 검토합니다. 지금은 placeholder입니다. PWA/production save/cloud sync도 범위 밖입니다.
