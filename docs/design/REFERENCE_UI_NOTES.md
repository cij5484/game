## 2. 승인된 요구에 적용

- **상단 빌드 바:** 얇은 반투명 띠 안에 `기본 강화 합산 → 무기 특성 → 유물 → 확장 코어`를 간격·구분선으로 묶는다. 획득 항목만 표시하고, 각 아이콘 내부에 레벨/합산 수를 둔다. 기본 강화 합산은 해당 계열에 투자한 랭크 합계이며 개별 효과의 단일 레벨로 오해되지 않게 접근성 설명을 제공한다. 빌드 바는 읽기 전용이다.
- **하단 통합 성벽 HUD:** 기존 성벽을 더 두껍게 사용해 HP, 레벨/XP, 시간과 스팀팩·장착 마법·필살기 상태를 모은다. 중앙 전투 공간에 별도 큰 패널을 추가하지 않는다. 스팀팩와 마법은 상태 표시이며 기존 터치·제스처 입력을 유지한다. 필살기는 준비됐을 때 수동 버튼이다.
- **원형 진행 표시:** 아이콘 중심은 유지하고 바깥 진행을 12시 시작·시계방향으로 통일한다. 마법은 재사용 준비도, 필살기는 실제 충전도, 스팀팩는 현재 단계의 진행도를 사용한다. 스팀팩 `강화/탈진/회복/준비`, 마법 `대기/준비`, 필살기 `충전/준비`를 짧은 한국어 문구로 보완한다. 색만으로 상태를 구분하지 않는다. 이 원형 표현은 레퍼런스의 확인된 기능이 아니라 **사용자 요청을 구현하기 위한 프로젝트 설계**다.
- **일시정지:** 우측 최상단에 고정하고 빌드 바가 버튼 영역을 침범하지 않게 한다. 시각 아이콘이 작더라도 터치 영역과 한국어 접근성 이름은 확보한다.
- **세로 모바일:** safe-area 안에 정보·버튼을 두고 배경은 화면 전체를 채운다. 좁은 폭에서도 아이콘 레벨과 필살기 조작을 읽을 수 있게 유지한다. 툴팁 hover에 필수 정보를 의존하지 않으며 긴 설명은 선택·정지 화면에서 읽는다. 최대 보유 상태에서 겹침·가로 넘침이 없는지 확인한다.

## 3. 경계와 확인 항목

기존 `GAME_GDD_v0.2.md` §4의 “상단 Battlefield 전용 / 유물 하단 배치”는 이번 상단 빌드 바 요청에 맞춰 본 작업의 문서 담당자가 갱신한다. 한국어 우선, Full-Bleed, 독립 HUD root, 마법 표시 비버튼, 필살기 수동 발동은 유지한다.

확인할 장면은 초기 빌드, 모든 보유 슬롯과 일반 강화가 채워진 빌드, 쿨다운 0/중간/완료, 스팀팩 각 단계, 필살기 준비, 일시정지·재개, 좁고 긴 세로 화면이다. 레퍼런스 조사는 가독성 방향의 근거이며 실제 기기 터치 품질·재미·밸런스 승인으로 취급하지 않는다.
