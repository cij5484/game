## 유지한 기준

M3가 쉽다는 실제 플레이 피드백을 반영해 **적 수와 보충량**을 올린다. HP Sponge나 추가 이동속도 상승으로 난이도를 만들지 않는다. Header / Battlefield / Bottom, mask, logical progress, 사거리 기본 `.55`, 초기 단발 `800ms / damage10`, 스팀팩, V 필살기, Pause/Restart를 유지한다.

Grunt / Runner / Shield의 기본 progress/s는 `.032 / .075 / .025`, 생성 시 속도 배율은 `.975 → 1.53`으로 **M3의 M2 대비 1.5배 유지**다. 일반 적 HP `8 / 10 / 20`, Shield 물리 방패30, 생성 HP 곡선과 두 Elite의 행동/시점도 변경하지 않았다. Marine Legacy Magic은 계속 비활성이다.

## 성장 상태와 XP

기존 인터페이스에 맞춘 Marine 전용 작은 상태 `MarineProgression`을 연결했다. `rank`는 실제 획득 Level, `quality`는 희귀도별 누적 효과, `legendary`는 소유한 전설 개조다. Legacy `Progression`을 새 구조로 덮어쓰지 않는다.

Character L의 다음 요구 XP는 `ceil(8 + 4(L−1) + .35(L−1)²)`. 이전 `8 + 6(L−1) + 2(L−1)²`보다 완만하다. 적 XP1/1/3과 Elite 보상은 유지한다. 초과 XP/밀린 선택을 보존하고 선택 중에는 전투 시간을 진행하지 않는다. 공용3종과 개조6종은 Level 상한이 없다. 계산상 효과가 없는 속도/치명 카드는 제외하며, 피해와 보유 개조 등 유효한 반복 후보가 남는다.

### 공용 강화와 희귀도별 실제 증가량

아래 값은 **획득 Level 하나당** 누적된다. `q`는 해당 카드의 누적 quality다. 대성공은 실제 증가한 Level만큼 quality도 더한다.

| 카드 | 일반 | 희귀 | 유니크 | 전설 | 실제 효과 |
| --- | ---: | ---: | ---: | ---: | --- |
| 공격력 | .18 | .30 | .46 | .66 | 기본 피해 ×(1+q) |
| 공격속도 | .08 | .125 | .18 | .24 | 전체 공격 Cycle ÷(1+q) |
| 치명타 확률 | .055 | .09 | .14 | .20 | 5% + 95%×q/(1+q), 100% 미만 |
| 형태 개조 quality | 1 | 1.6 | 2.4 | 3.2 | 아래 개조별 계산에 사용 |
| 사거리 | 없음 | .03 | .045 | .06 | 최소 progress `.55−q`, 하한 .25 |

치명타 배율은 기존1.75 고정이다. 공용 효과는 현재 Gauss에 적용하며 특수무기 coefficient나 새 무기 시스템은 만들지 않았다.

### 기본무기 6개조

서로 다른 최대3종. 최초Lv1, 같은 카드는 반복 성장하고 Lv3/Lv6 분기 선택은 없다. 아래 `r`은 Level, `q`는 해당 개조 quality다. 투사체/검색량에 상한을 둬도 피해·효율 숙련은 Lv11+에 계속 성장한다.

| 개조 | 첫안 성장 및 자연 조합 |
| --- | --- |
| 관통 | 추가 관통 `min(8, 1+floor((r−1)×.7))`명. 후속 유지율 `.6+.35q/(q+5)`, 방패 우회 `.5q/(q+12)`. 실제 직선 뒤의 적을 타격 |
| 도탄 | `min(6,1+floor((r−1)/2))`회. 탐색 반경 보너스 `min(90,7q)`, 후속 유지율은 관통과 동일, 매 연결 피해 보너스 `.01q`. 같은 연결에서 재방문 금지 |
| 점사 | Lv1에서2발, 두 Level마다1발 증가, 일반 최대7발. round 간격 `max(55,155/(1+.055q))ms`, 개별탄 숙련 피해 ×(1+.035q) |
| 다중탄 | 주탄 외 `min(5,1+floor((r−1)/2))`보조탄, 피해 배율 `.5+.065q`, 확산각 `min(1.3,.65+.04q)`. 서로 다른 유효 표적 우선 |
| 폭발탄 | 반경 `min(130,60+6q)`, 피해 배율 `.35+.075q`. 직접 적중뿐 아니라 관통/도탄 지점에서도 자연 적용 |
| 고위력 단발 | 개별탄 피해 ×(1+.45q), Cycle 패널티 `1.2+.15/(1+.15q)`. 점사/공격속도와 동시 적용, 큰 tracer 사용 |

공격 Cycle은 `max((rounds−1)×roundInterval+100ms, 800ms×heavyPenalty/(1+speedQuality))`. 점사는 시간차 발사이고 다중탄은 같은 발사 시점의 여러 방향 공격이다. 공용 공격속도는 round 간격 자체를 줄이지 않는다. **기존 스팀팩 등 일시적 속도 버프는 전체 무기 시계를 배속**하므로 점사 간격도 함께 짧아진다. 이를 새 공용 공격속도 규칙과 구분한다. 진행 중 점사는 시작 시 설정을 유지하고 새 설정은 다음 Cycle부터 쓴다. Tap이 별도 발사/예약을 만들지 않는다.

한 round에서 동일 적의 여러 효과는 기존 strongest-hit 규칙으로 처리한다. 동일 적에게 겹친 모든 AoE를 무제한 합산하지 않는다. 대상 검색128 / splash검색64 / splash대상24 제한을 재사용한다. Echo는 quality/전설까지 스냅샷하며 기존 유물 Level별 상속 제한을 유지한다.

### 대표 전설 변형

- 관통: 관통 끝점 충격파, 반경100 / 피해 배율 `.65+.035q`.
- 점사: 같은 Cycle의 시간차 마무리탄 +1, 최대8발.
- 폭발탄: 폭발 처치 적 중 최대2명에서 한 번만 재폭발, 반경75 / 배율 `.3+.035q`. 재귀 연쇄 없음.

나머지 도탄/다중탄/고위력의 별도 전설 행동은 후속이며 현재는 전설 quality만 적용한다. 전설이 +3 Level로 바뀌지 않는다. 같은 개조의 전설을 이미 보유하면 그 카드의 전설 등급을 후보에서 제외하고 남은 등급 가중치를 재정규화한다. 보통 등급의 반복 Level 성장은 유지한다. 서로 다른 전설의 동시 보유는 가능하다.

### 후보 / 사거리 / 대성공

카드 종류 weighted sampling without replacement → 각 카드 희귀도 → 선택 후 별도 대성공 순서다. 기본3장 중1장, Reroll/pity/시너지 한 자리 보장 없음.

| Character Level | 일반 | 희귀 | 유니크 | 전설 |
| --- | ---: | ---: | ---: | ---: |
| 1–9 | 78% | 20% | 1.9% | .1% |
| 10–19 | 68% | 27% | 4.7% | .3% |
| 20–29 | 58% | 33% | 8.4% | .6% |
| 30+ | 50% | 36% | 13% | 1% |

기본 type weight는 공용1, 개조1.3, 사거리.25. 최종 weight는 `base × min(2,1+.1×rank)`. 투자 가중치는 희귀도와 무관하다. 사거리는 Common을 제외하고 Rare/Unique/Legendary를 재정규화한다. 개조 슬롯을 사용하지 않으며 최대5Level, 최대 원거리 한계progress .25다. 일반적인 희귀5회는 .55→.40, 전설5회라면 .25다. Gold 연구는 미구현이다.

대성공은 독립6%, 총+2Level. Range Lv4에서는 실제+1만 적용해 Lv5를 넘지 않고 효과도+1분만 지급한다. 피드백도 실제 증가분과 MAX 도달을 표시한다. 특수무기 마일스톤 Queue는 현재 무기가 없으므로 새로 구현하지 않았다.
