권장 추론 수준: High

현재 게임의 Weapon Trait / Relic / Synergy를
재미와 역할 구분 중심으로 재설계한다.

중요:
- 현재 branch `codex/milestone-12-combat-depth`에서 계속 작업한다.
- 사용자가 로컬에서 별도로 밸런스/호드 수정도 진행했다.
- 과거 commit SHA를 기준으로 reset / checkout / hard reset 하지 않는다.
- 작업 시작 시 현재 HEAD와 git status를 먼저 확인한다.
- 사용자의 최신 변경사항을 보존하고 그 위에 통합한다.
- 아직 main에 merge하지 않는다.

이번 작업은 단순히 "콘텐츠 숫자 늘리기"가 아니다.

목표:
1. 역할이 겹치거나 재미가 약한 무기 특성 제거
2. 플레이 방식이 실제로 달라지는 신규 무기 특성 추가
3. 재미가 약하거나 다른 시스템과 역할이 겹치는 유물 재설계
4. 현재 늘어난 선택지들을 연결하는 다양한 Synergy 확대
5. 성공한 유사 장르의 검증된 설계 원칙 적극 참고
6. GDD v0.2와 레퍼런스 문서 갱신

────────────────────
0. Reference-Driven Design
────────────────────

구현 전에 현재 성공적인 유사 게임의
무기 성장 / Overclock / 상태효과 / 시너지 / 아이템 상호작용 사례를 조사한다.

우선 참고:
- 20 Minutes Till Dawn
- Deep Rock Galactic: Survivor
- Brotato
- HoloCure
- Soulstone Survivors
- Vampire Survivors

특히 조사할 것:

- 단순 스탯 강화와 행동 변화 업그레이드를 어떻게 구분하는지
- 서로 다른 무기 효과가 어떻게 조합되는지
- 상태효과가 다른 효과를 연쇄적으로 발생시키는 구조
- 무기 + 아이템 / 무기 + 상태 / 무기 + 무기 조합
- 강력한 Build가 만들어질 때 플레이어가 어떻게 알아차리는지
- 재미있는 Risk / Reward 아이템
- "A를 하면 B가 발생한다" 형태의 패시브 설계

특정 게임의 이름/아트/UI를 복제하지 않는다.

좋은 원리를 우리 게임:
- 세로 화면
- Horde
- 직접 Target Tap
- Gesture Magic
- 스팀팩
- 성벽
구조에 맞게 재설계한다.

조사한 핵심은
`docs/design/REFERENCE_UI_NOTES.md`
또는 적절한 Reference 문서에 추가한다.

────────────────────
1. 기존 Weapon Trait 정리
────────────────────

현재 특성 중 아래 3종을 Weapon Trait에서 제거한다.

삭제:
- 분열탄
- 중량탄
- 치명타

이유:

분열탄:
도탄과 실제 플레이 체감/화면 행동이 너무 유사하다.

중량탄:
현재 핵심이 피해 증가 + 밀치기라
독립적인 Trait로서 행동 변화가 약하다.

치명타:
치명타 확률은 이미 "기본 강화" 시스템으로 이동했다.
따라서 Weapon Trait 슬롯을 따로 차지하게 하지 않는다.

중요:
치명타 확률 기본 강화와
치명타 기반 Synergy 자체는 유지 가능하다.

기존 저장/테스트/표시 코드에서 제거하면서
orphan id / dead effect가 남지 않게 정리한다.

────────────────────
4. 소이탄
────────────────────

역할:
즉시 폭발과 다른 "지속 피해 / 전염" Build.

핵심:
적중한 적에게 화상 상태를 부여.

폭발탄:
즉시 범위 피해

소이탄:
시간에 걸친 지속 피해 + 전염

둘의 역할이 명확히 달라야 한다.

Lv 성장 예:

Lv1:
- 적중 시 화상
- 짧은 지속 피해

Lv2:
- 화상 피해/지속 강화

Lv3:
- 화상 적 사망 시 주변 적 1~2명에게 화상 전염

Lv4:
- 전염 범위/강도 상승

Lv5:
- 강한 화상 연쇄
- 다만 무한 chain은 방지
- 성능 비용을 고려해 chain depth / target cap 필요

정확한 수치는 data-driven.

────────────────────
5. 표식탄
────────────────────

이 Trait은
우리 게임의 "적 직접 Tap Target" 시스템을 적극 활용한다.

역할:
중요한 한 적을 집중해서 제거.

같은 적에게 연속 적중하면
표식 stack 또는 약점 상태가 쌓인다.

Lv 성장 예:

Lv1:
- 연속 적중 시 표식
- 표식된 적에게 추가 피해

Lv2:
- 최대 stack 증가 또는 stack 효율 상승

Lv3:
- MAX 표식 시 약점 노출
- 추가 피해 또는 방어 일부 무시

Lv4:
- 표식 적 처치 시 인접 위험 적에게 일부 표식 이전

Lv5:
- MAX 표식 대상에 강력한 마무리 효과
- Elite / Shield 대응 가치 상승

Smart Auto Target도 작동하지만
수동 Target Tap을 잘 사용하면
더 효율적이어야 한다.

이 Trait은
"플레이어의 조작 실력과 판단"을 강화하는 방향으로 설계한다.

────────────────────
6. 제압탄
────────────────────

역할:
DPS가 아니라 국지적인 전선 통제.

Frost와 역할이 겹치면 안 된다.

Frost:
전장 전체를 일정 시간 느리게 하는 장기 전역 제어

제압탄:
사격으로 특정 적/전선을 밀어내는 국지 제어

예:

- 명중으로 제압 stack
- 일정 stack에서 이동 저하
- 높은 단계에서 작은 Pushback
- 성벽 공격 중 적의 다음 공격 지연 가능

Lv5 후보:
제압 임계 도달 시
뒤쪽 적까지 영향을 주는 충격파 또는 군중 밀침.

무한 stun-lock은 금지.

Boss/Elite에는 효과를 낮추는 식으로
향후 확장 가능한 구조 유지.

────────────────────
7. 과열
────────────────────

역할:
사격 리듬 자체를 바꾸는 Risk / Reward Trait.

지속적으로 공격할수록 Heat 증가.

Heat가 올라가면:
- 공격속도
또는
- 공격력

이 상승.

하지만 너무 높은 Heat에서는
Overheat 위험이 생긴다.

잠시 공격을 쉬면 냉각.

목표:
단순 "공격속도 +10%" 카드가 아니라

계속 공격할 것인가
잠깐 식힐 것인가

라는 플레이 판단을 만든다.

Lv 성장 예:

Lv1:
- Heat system 활성
- Heat에 따른 작은 보너스

Lv2:
- 고Heat 보너스 상승

Lv3:
- 특정 Heat 이상에서 추가 행동

Lv4:
- 최대 Heat / 냉각 효율 개선

Lv5:
- Redline 상태
- 매우 강하지만 Overheat 대가 존재

기본 공격 입력 buffer와 충돌하지 않게 한다.

────────────────────
8. 기본 강화와 치명타 역할
────────────────────

기본 강화는 현재처럼:

- 공격력
- 공격속도
- 치명타 확률

유지.

치명타 피해 배율은 현재 사용자가 조정한 최신 값을 존중한다.

Weapon Trait로서 "치명타"는 제거.

하지만 치명타는:
- Synergy 조건
- 유물 조건
- 전설 강화
에서 사용할 수 있다.

즉:

치명타 확률 = 기본 강화

치명타가 다른 행동을 유발 = Synergy / 유물 / 고급 강화

로 역할 분리.

9. Relic 재설계
────────────────────

현재 Relic 8종을 검토한다.

유지 또는 기본 철학 유지:
- 테슬라 코일
- 광전사 인장
- 시간 톱니

최후의 보루:
- 단순 수치 패시브가 아닌 이벤트형으로 재설계

교체:
- 공성 증폭기
- 얼음 심장
- 자극 회로
- 행운 동전

행운 동전은 특히 제거한다.

이유:
이미 "행운 코어"가
희귀도 가중치 조작 역할을 담당해
시스템 역할이 겹친다.

10. 신규 Relic — 탄약 복제기
────────────────────

역할:
공격 자체를 눈에 보이게 복제.

예:

일정 횟수의 기본 공격 후
방금 사용한 점사를 짧은 지연 뒤
다른 적에게 Echo Shot으로 복제.

Lv 성장:

Lv1:
- 비교적 긴 주기로 약한 복제

Lv2:
- 발동 주기 개선

Lv3:
- 복제 공격이 일부 Trait 효과 계승

Lv4:
- 더 많은 탄 / 더 강한 복제

Lv5:
- 강력한 Full Echo
- Trait 효과 대부분 계승

무한 재귀:
복제탄이 다시 복제기를 발동하면 안 된다.

────────────────────
11. 신규 Relic — 서리 공진기
────────────────────

기존 얼음 심장의
단순 Frost 지속시간 증가 중심 설계를 대체.

역할:
Magic → Primary 연결.

Frost 활성 상태 적에게
기본 공격을 맞히면 "취성" 축적.

일정량 누적:
→ 파쇄
→ 주변에 냉기 피해/파동.

Lv이 올라갈수록:
- 취성 축적 속도
- 파쇄 피해
- 파쇄 범위
- 연쇄 가능성
등 증가.

Frost 자체를 강화하는 것이 아니라
"Frost 상태를 총으로 활용"하는 유물.

────────────────────
12. 신규 Relic — 아드레날린 펌프
────────────────────

기존 자극 회로를 대체.

역할:
스팀팩의 Kill Momentum 강화.

예:

스팀팩 강화 상태에서 적 처치:
→ Boost 지속시간 아주 조금 연장.

반드시:
- 횟수/시간 상한 존재
- 무한 지속 불가

Lv 증가:
- 연장량 증가
- 최대 연장량 증가
- 특정 레벨에서 추가 공격 보너스

Lv5:
강력한 Redline 효과 가능.

대가:
긴 Boost를 얻을수록
Crash/Recovery 부담이 일부 증가하는 Risk/Reward도 검토.

단 기존 Crash 1초 핵심 정체성은 함부로 제거하지 않는다.

────────────────────
13. 신규 Relic — 긴급 회수 장치
────────────────────

역할:
성벽 근처 전투 ↔ 생존 연결.

예:

성벽에 가까운 적을 처치:
→ 소량의 에너지 회수
→ 성벽 HP 미량 회복

반드시:
초당 또는 이벤트당 회복 cap 필요.

Lv5:
Run당 1회,
성벽이 치명적 피해를 받을 때:

- 치명 피해 방지
- 긴급 방벽
- 성벽 앞 적 Pushback
- 시각적 Emergency effect

등의 강한 사건 발생.

단순 HP +% 유물이 아니다.

────────────────────
14. 최후의 보루 재설계
────────────────────

현재의 지속적인
저HP 수치 보너스 중심에서 벗어난다.

"위기 이벤트" 유물로 변경.

예:

성벽 HP가 처음 30% 아래로 내려갈 때
Run당 1회 비상 방어 모드 발동.

효과 예:
- 주변 적 밀어냄
- 일정 시간 공격속도 상승
- Magic cooldown 일부 회복
- 짧은 보호막 또는 피해 경감

Lv1~5에서
효과/지속/보호 능력이 강해진다.

플레이어가:

"최후의 보루가 발동했다"

를 화면에서 즉시 알아야 한다.

16. Hyper Gauss Evolution migration
────────────────────

기존 Hyper Gauss가
공성 증폭기 제거 때문에 깨지지 않게 한다.

새 Recipe 후보:

관통 Lv.4 이상
+
테슬라 코일 Lv.3 이상
→ 초관통 가우스 / Hyper Gauss

이 조합은:
전자기 증폭 Gauss라는 테마로 자연스럽다.

기존 Hyper Gauss 동작:
- 추가 관통
- 넓어진 관통 폭
- 강화 tracer

은 유지 또는 현재 Trait 구조에 맞게 정리.

Recipe는 data-driven 유지.

────────────────────
17. Synergy System 확장
────────────────────

현재 3개뿐인 Synergy를 확대한다.

중요:
모든 가능한 조합에 억지로 시너지를 만들지 않는다.

원칙:
Synergy는
"두 숫자를 더함"
이 아니라

"새로운 행동이 발생함"

이어야 한다.

Prototype에서는
총 10~12개 정도 실제 구현을 목표로 한다.

현재 유지/마이그레이션:

1. 심층 폭발
관통 + 폭발탄
→ 관통 적중마다 폭발

2. 살상 도탄
도탄 + 치명타 확률 기본 강화 일정 rank
→ 치명타 도탄이 추가 행동

기존 치명타 Trait 조건은 제거한다.

3. 탄막 폭풍
다중탄 + 공격속도 기본 강화
→ 일정 발사마다 추가 탄막

────────────────────
18. 신규 Synergy 후보
────────────────────

아래에서 플레이 체감이 명확하고
구현 비용이 합리적인 것부터 선택해
총 10~12개까지 실제 구현한다.

A. 화염 궤적
관통 + 소이탄
→ 관통한 모든 적에 강한 화상
→ 마지막 관통 지점에서 작은 화염 파동

B. 화염 도탄
도탄 + 소이탄
→ 도탄마다 화상 적용
→ 마지막 도탄은 주변 적에게 화상 전염

C. 집속 폭격
다중탄 + 폭발탄
→ 보조탄도 작은 폭발
→ 중앙탄은 강화 폭발

D. 즉결 폭파
처형탄 + 폭발탄
→ 처형된 적이 강한 폭발 발생

E. 사냥감 처형
표식탄 + 처형탄
→ MAX 표식 적의 처형 기준 강화
→ 처형 성공 시 표식 일부 이전

F. 제압 관통
관통 + 제압탄
→ 관통한 적 모두 제압 stack
→ 마지막 관통에서 짧은 충격파

G. 과열 탄막
과열 + 다중탄
→ 높은 Heat에서 추가탄 증가
→ 대신 Heat 상승도 빨라짐

H. 열충격
소이탄 + 서리장
→ 불타는 적이 Frost 영향을 받을 때
   즉시 Thermal Shock 피해
→ 화상/냉기 상호작용 발생

I. 전도 표식
표식탄 + 연쇄 번개
→ 연쇄 번개가 표식 적을 우선 탐색
→ MAX 표식 대상에는 강한 Arc

J. 극저온 냉각
과열 + 서리장
→ Frost 사용 시 Heat 일부 또는 전부 냉각
→ 짧은 Overclock window 제공 가능

K. 제압 처형
제압탄 + 처형탄
→ 완전 제압된 적은 처형 조건이 일부 완화

L. 폭발 도탄
도탄 + 폭발탄
→ 도탄마다 작은 폭발
→ 마지막 도탄 대형 폭발

모든 효과에는:
- 재귀 방지
- target cap
- chain depth
- effect budget

중 필요한 안전장치를 둔다.

300마리 Horde에서도 성능 폭발하지 않게 한다.

────────────────────
19. Synergy 층위
────────────────────

공식 설계 원칙:

[자연 상호작용]
특성이 기본적으로 동시에 적용되는 것.
별도 이름 없음.

예:
다중탄에도 관통 적용 가능.

[시너지]
특정 조합이 충족되면
새 행동 자동 활성.

별도 슬롯 없음.

[진화]
높은 Trait / Relic 등 조건으로
한 시스템이 상위 형태로 변화.

[비밀 진화]
Trait + Magic + Relic 등
복잡한 조건의 고급 숨은 조합.

이 네 층을 코드와 GDD에서 혼동하지 않는다.

20. Synergy UX
────────────────────

예:
짧은 화면 알림

🔥 화염 도탄"

정도.

상단 Build Bar에도
활성 Synergy를 작은 전용 아이콘으로 표시할 수 있다.

상세 조건/효과는
일시정지 Build 상세에서 확인.

전투 화면 텍스트 과밀은 피한다.

────────────────────
21. 코어 역할 유지
────────────────────

Core는 Synergy Recipe 재료로 남발하지 않는다.

Core는 Run 규칙 자체를 변경하는 역할.

현재 예:
- Trait 슬롯 확장
- Relic 슬롯 확장
- 희귀도 변경
- Trait 성장
- Synergy 강화

특히 공명 코어:
→ 현재 활성 Synergy를 강화

라는 철학을 유지.

Core와 Relic 역할을 다시 섞지 않는다.
