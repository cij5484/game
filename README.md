# Horde Defense Prototype

모바일 웹 호드 디펜스의 그레이박스 프로토타입입니다. **Current Source of Truth: [GDD v0.3 — Marine Primary + Special Weapons Architecture](docs/design/GAME_GDD_v0.3.md)**. v0.3은 목표 설계이며 이번 패스에서는 구현하지 않았습니다. 현재 코드와의 차이는 [Current Implementation Gap](docs/design/GAME_GDD_v0.3.md#18-current-implementation-gap)에 기록합니다. [GDD v0.2](docs/design/GAME_GDD_v0.2.md)는 과거 기록으로 보존하고, [Reference Notes](docs/design/REFERENCE_UI_NOTES.md)의 Main Reference는 DRG: Survivor와 20 Minutes Till Dawn입니다.

아래 조작·수치·성장 설명은 `0489ef9`의 **현재 구현 스냅샷**입니다. v0.3의 특수무기·공용 성장·새 UI가 구현됐다는 뜻이 아닙니다.

## 한 판과 조작

- 성벽 HP12,000으로 전투 시뮬레이션300초를 버티면 승리합니다. 선택창과 수동 일시정지는 시간을 멈춥니다. 영구 보상·Run 저장/불러오기는 없습니다.
- 기본 공격은 **입력 없이 자동 발사**합니다. 가우스 소총은 기본200ms마다 피해10이며 연타로 DPS가 늘지 않습니다. 적을 Tap하면 그 적을 계속 집중 공격하고, 빈 전장을 Tap하거나 대상이 죽으면 성벽에 가장 가까운 적을 자동 조준합니다.
- **서리장: ○ 또는 하단 아이콘 / 연쇄 번개: Z 또는 하단 아이콘.** 제스처와 버튼은 같은 효과와 대기시간을 공유합니다.
- **스팀팩: 두 손가락 Tap / PC 좌우 마우스 동시 클릭 / 하단 아이콘.** 기본 강화5초×1.5 → 반동1초(공격 불가) → 회복2초이며 정상 상태에서 다시 사용합니다. PC 합류120ms/릴리스300ms, 그리기 최대5초/Tap300ms입니다.
- **필살기: 충전100%에서 V 제스처로 즉시 발동.** 왼쪽 위 → 아래 꼭짓점 → 오른쪽 위로 그립니다. 반대 시작 방향도 인식합니다. 아이콘 Tap은 경로 힌트만 표시하며 필살기를 발동하지 않습니다. 리듬·타이밍 등급·슬로모션은 없습니다.
- 일시정지에서 상세 빌드를 확인하거나 다시 시작할 수 있습니다. 재도전은 분기·시너지·집중 타겟·유물·코어·타이머를 포함한 Run 전체를 초기화합니다.

## 선택형 성장

처치 XP는 Grunt/Runner1, Shield3이며 다음 요구 XP는 `8+6(L−1)+2(L−1)²`입니다. 초과 XP와 밀린 선택을 보존합니다. 기본 강화는 공격력+15%, 공격속도+6%, 치명 확률+5%p의3종, 각각 최대5회입니다. 기본 치명 확률5%·피해×1.75를 유지합니다.

Marine 무기 특성은 **관통·도탄·다중탄·폭발탄·처형탄**5종입니다. 기본3종, 전술 확장 코어로4종을 보유합니다. 각 특성은 Lv1 기능 → Lv2 강화 → **Lv3 A/B 선택** → Lv4 선택 분기 강화 → **Lv5 결실**로 성장합니다. 반대 분기는 같은 Run에서 잠깁니다.

| 특성 | A: Lv3 → Lv5 | B: Lv3 → Lv5 |
| --- | --- | --- |
| 관통 | 직선 관통 → 무손실 관통 | 파쇄 관통 → 대형 파쇄 |
| 도탄 | 연쇄 도탄 → 전장 연쇄 | 강타 도탄 → 파괴 도탄 |
| 다중탄 | 광역 사격 → 전면 탄막 | 집중 사격 → 집중 일제사격 |
| 폭발탄 | 연쇄 폭발 → 연쇄 붕괴 | 압축 탄두 → 초대형 기폭 |
| 처형탄 | 사형 집행 → 최후 통첩 | 죽음의 파동 → 집단 선고 |

서리장·연쇄 번개·스팀팩도 각5단계 투자와 Lv3 A/B 선택을 사용합니다. 서리장은 **전장 제어 / 파쇄**, 번개는 **연쇄 / 낙뢰**, 스팀팩은 **고농도 투약 / 안정 투약**으로 운용이 달라집니다. 마법과 스팀팩은 강화 카드가 없어도 기본 능력을 사용할 수 있습니다. 기본 강화·마법·보조 기술·시너지는 무기 특성 슬롯을 사용하지 않습니다.

카드는 기본3장, 선택 확장 코어가 있으면4장입니다. Lv3 분기는 A/B가 같은 화면에 등장합니다. 카드 종류와 희귀도는 별개이며 MAX·반대 분기·한도가 찬 새 특성은 후보에서 제외합니다. Reroll은 없습니다.

## 시너지·유물·코어

시너지는 조건 충족으로 **카드를 해금**하고, 레벨업에서 **선택해야 활성화**됩니다. 해금했지만 미선택인 시너지 중1장을 다음 후보에 우선 배치하고 여러 조합은 적게 등장한 순서로 순환합니다. 별도 특성 슬롯을 소비하지 않습니다.

| 시너지 | 해금 조건 | 효과 |
| --- | --- | --- |
| 심층 폭발 | 관통1 + 폭발탄1 | 관통 지점마다 폭발 |
| 살상 도탄 | 도탄1 + 치명 확률 강화1 | 치명타 피해를 이어가는 추가 도탄2회 |
| 탄막 폭풍 | 다중탄1 + 공격속도 강화3 | 매4번째 발사에 온전한 피해의 추가탄2발 |
| 집속 폭격 | 다중탄1 + 폭발탄1 | 중앙탄 강화 폭발·보조탄 작은 폭발 |
| 즉결 폭파 | 처형탄1 + 폭발탄1 | 처형 성공 시 강한 폭발, 재귀 처형 없음 |

유물은 **테슬라 코일·광전사 인장·시간 톱니·최후의 보루·탄약 복제기·서리 공진기·아드레날린 펌프·긴급 회수 장치**8종입니다. 기본3종/확장4종, 각Lv1~5이며 같은 유물을 고르면 강화됩니다. 정예 처치는 별도 유물 선택을 제공합니다. 탄약 복제기는 Lv1~5에서 자동 사격24/18/15/12/9발마다2/2/3/3/3발을 복제합니다.

정예 처치 시8%로 코어를 별도 추첨하며 한 Run 최대2개, 종류 중복은 없습니다.

| 코어 | 효과 |
| --- | --- |
| 전술 확장 | 특성 한도3→4 |
| 유물 확장 | 유물 한도3→4 및 즉시 추가 유물 선택1회 |
| 공명 | 선택해 활성화한 시너지 효과×1.5 |
| 선택 확장 | 레벨업 후보3→4장 |

행운 코어는 선택 확장으로 교체했고, 분기 선택을 건너뛰던 과부하는 제거했습니다. **관통Lv4 + 테슬라 코일Lv3 → 초관통 가우스** 진화는 유지합니다. 소이탄·표식탄·제압탄·과열과 해당 조합은 이번 Marine 후보에서 제거했습니다.

## 마법과 필살기

서리장 기본은 전역 이동속도×0.5/7초/대기30초, 연쇄 번개 기본은 최대30명/피해75/연결거리360/대기24초입니다. 강화 중인 대기시간은 카드 선택으로 초기화하지 않으며 빈 전장 시전도 대기를 소모합니다. 각 분기의 수치와 최종 행동은 GDD를 따릅니다.

필살기 억제 사격은 **성벽 가까운 최대60명에게 각140피해**를 즉시 적용하며 방패 저항·무기 특성과 독립적입니다. 일반 전투 충전은 명중0.02/처치0.08, 기여 예산 최대3과 초당0.45 회복으로 제한됩니다. 정예 처치는 별도로+6입니다. 시간만으로 게이지가 차지 않고 필살기 처치는 게이지를 재충전하지 않습니다. Run당1~2회의 희귀 이벤트를 목표로 하며 현재 보수적 충전값은 실제 플레이에서 검증해야 합니다.

## 화면과 검증

Phaser RESIZE/720×1280 논리 전장/Full-Bleed를 유지합니다. 상단 Build Bar는 작은 기호와 레벨을 표시하고 상세는 일시정지에서 확인합니다. 하단 성벽에는 HP·레벨/XP·시간과 스팀팩·서리장·번개·필살기4칸이 있습니다. 앞3개는 실제 버튼이고 필살기만 제스처 힌트 버튼입니다. safe-area와 터치 스크롤/선택 억제를 적용합니다.

자동 공격·집중 대상, 분기 잠금과 최종 효과, 입력 경로 공유, 필살기 준비 조건과 ○/Z 충돌 거절, 시너지 선택, 코어 보상을 테스트합니다. 이번 통합 검증은34개 파일/215개 테스트, TypeScript 검사와 프로덕션 빌드를 통과했습니다. 아래 명령으로 재현할 수 있습니다. 실제 Android/iPhone의 제스처 재현성·다중 터치·노치·후반180마리 성능과 재미·승률·MAX 도달성은 별도 플레이테스트 대상입니다. Vite의 기존 번들 크기 경고도 남아 있습니다.

## 실행과 검사

Node.js와 npm이 필요합니다. Windows PowerShell에서 실행 정책이 npm 스크립트를 막으면 `npm.cmd`를 사용합니다.

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

브라우저에서 Vite가 출력한 Local 주소를 엽니다. 휴대폰에서는 같은 로컬 네트워크에 연결해 Vite의 Network 주소와 실제 포트를 사용합니다. IP는 바뀔 수 있습니다.

```sh
npm test
npm run test:watch
npm run build
npm run check
```

`check`는 테스트 후 TypeScript 검사와 프로덕션 빌드를 실행합니다.

현재 작업은 `codex/milestone-12-combat-depth`에서 계속합니다. main에 merge하거나 다음 Milestone을 시작하지 않고 사용자 플레이테스트를 기다립니다. 이전 구현·검증 기록은 Git 이력과 GDD의 과거 기록을 참고합니다.
